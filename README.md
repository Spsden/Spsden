## How I like to build

I tend to think end to end.

For me, building an AI feature is not just about calling a model.

It is also about:

- what context the model receives
- how tools are exposed
- where code executes
- how permissions work
- what happens when something fails
- how state is persisted
- how the user stays in control
- whether the interface actually feels good to use

I care a lot about the small details that sit between **technically working** and **actually being a good product**.
